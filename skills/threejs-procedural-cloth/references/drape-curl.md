# 包上支撐物、傾倒、翻角、縫邊、放東西、疊布

## 平面 → 世界：`place(mx, mz, e, eRef, o)`

依序做三件事：
1. **平面扭曲**：`X = mx + warpX`，`Z = mz + warpZ`，±2.2 cm 的低頻雜訊。目的是讓縫邊與折線不會筆直得像尺畫的。
2. **傾倒**：`amt = 0.42 · max(0, eRef - 0.055)`，往一個由雜訊決定的方向位移。
   - 因為位移量取決於高度，高的折頂部會偏向一邊，形成一邊陡、一邊緩（有時還會懸垂）的樣子。
   - 接近床緣時要淡出（`1 - smoothstep(-0.16, -0.03, overhang)`），否則會倒出床外。
   - `eRef` 用的是**該點布的高度**，不是目前頂點的高度。這樣布的上下兩面（以及翻過來的那片）會一起倒。
3. **drape**：`boxSupport({...}).drape(X, Z, e, o)`。
   - 平坦區會加上中間微凹（sag 7 mm）。
   - 越過 `P0`／`P1` 後沿半徑 r 的圓角包下去，再垂直往下。
   - e 會沿法線方向往外推，所以布的厚度在轉角處依然正確。

換成其他支撐物時，只要寫一個新的 `drape(p, z, e, o)` 就好：
- 圓桌：用極座標，r 越過桌緣就往下。
- 椅背：平面座標沿椅背曲線展開。
- 角色身上：這套方法不適合，請用模擬或骨架。

## 翻角（page curl）

- 折線：一個點 `FL0` 加法向 `FN`（指向會被翻起來的那側）。`q = dot(p - FL0, FN)` 再加一點正弦擺動，讓折線不會筆直。
- `q > 0` 的點：
  1. 先投影到折線上：`(lx, lz) = p - FN·q`。
  2. `curl(q, 折線處布高, 翻起那片的厚度)` 會回傳：
     - `q < 2.4R`：沿半徑 R 的圓筒捲上去，`w = R sin θ`，`e = R(1 - cos θ)`。
     - 之後：`w = -(q - qr)`，往回平躺。高度取「新位置的布高 + 翻起那片的厚度」，`eRef` 也用新位置的布高。
  3. 上表面 A 會塞進折線裡（`tq = min(q, 0.03)·0.6`，高度 −1 mm），從外面看不到。
- 網格分成三份：
  - 上表面：cell 的最小 q < 0.012。
  - 翻起那片：B 面，最大 q > −0.012，`flip`（翻起來後看到的是反面）。
  - 垂下部分的底面：B 面，stride 2。
- **被翻片蓋住的區域一定要設為平整區**（見 shape.md）。

## 縫邊（hem）

```
BAND = 1.6 cm（雙層車縫的平帶）  HEM = 3.6 mm（平帶厚度）
hemProf(ed) = prof(ed - BAND, 0.07)^1.25        // 車線內側 7 cm 內，填充物才把布撐起來
E = max(2.4mm, H·pr + 平帶·(1-pr) + 皺縮 - 1.1mm·車線凹槽)
```

- 網格在縫邊附近要更密：`zonedAxis` 會自動讓兩端的格子縮小，所以縫邊是真的幾何。
- 縫線本身用沿著外緣的 CatmullRom 曲線做成細管（半徑 1.7 mm）。外緣在翻角那一段要改取 B 面。
- 原專案還有床尾的鈕扣列：鈕扣之間的布用 `sin²` 張開一點，露出下層；另外有洗標。這些屬於加分細節。

## 在布上放東西

給定一個平面位置，用 `dvElev(mx, mz)` 取得布面高度，再 `place(mx, mz, e + 抬高, e, o)`，就能得到世界座標。
- 髮圈：40 個點繞一圈，每點都 `onDuvet(...)` 後連成管子，自然會沿著布起伏。
- 手機、書：取 3 個點算法向，用 quaternion 對齊。書另外要把底下的布壓平（shape.md 第 6 節）。

## 疊第二層布（毯子放在棉被上）

毯子的支撐物就是棉被：
1. 世界座標的 (X, Z) 先反推回棉被的平面座標（扣掉 warp，迭代一次就夠準）。
2. 支撐高度 = `dvElev`。
3. 毯子自己的起伏 `thLift` 加在上面。
4. 最後仍然用棉被的 `place(..., eRef = 棉被高度)` 放置，毯子就會跟著棉被一起倒、一起垂。

原專案的寫法：
```js
function duvetSupport(X, Z, o) {
  const mx = X - warpX(X, Z), mz = Z - warpZ(X, Z);
  o.mx = X - warpX(mx, mz); o.mz = Z - warpZ(mx, mz); o.e = Math.max(0, dvElev(o.mx, o.mz));
}
```

在毯子覆蓋的範圍，棉被要設為平整區（`tm`）。
