# 各 pass 的做法與數值

## 流程

```
scene ─► rtMain（HalfFloat、MSAA 4、DepthTexture）
          ├─► AO（半解析度）─► 水平模糊 ─► 垂直模糊 ─┐
          └──────────────────────────────────────────┴─► 合成（顏色 × AO、窗外 × ext、上限 60）─► rtComp
rtComp ─► 6 層降採樣 ─► 由小往大升採樣（相加）─► bloom
rtComp + bloom ─► 調色 ─► 畫面
```

全部用全螢幕三角形（比四邊形少一條對角線上的重複像素），自己寫 ShaderMaterial，不經過 EffectComposer。
render target 共 10 張：主畫面、AO 兩張、合成，以及 6 層 bloom。

## AO（接觸陰影）

- **由深度重建位置**：用 `projectionMatrixInverse` 把深度轉回 view space。
- **法線**：在左右、上下各取兩個單邊差分，**選 z 變化較小的那一個**。在物體輪廓上不會把前景和背景混在一起，所以不會產生一圈亮邊或暗邊。
- **14 個取樣**：分布在法線半球上（cosine 加權），方位角是黃金角螺旋；半徑在 0.12–1 倍 `aoRadius` 之間，以平方分布，讓近處的取樣比較多。
- **雜訊**：用 interleaved gradient noise（IGN）旋轉取樣，再加上 `frame` 讓每一格的雜訊不同。
  靜止畫面和錄影時要固定 frame，否則 AO 會閃。
- **遮擋判斷**：取樣點比深度圖上的點後面超過 2.5 mm，就算被遮住；權重乘上 `range = smoothstep(radius / |P.z − sz|)`，所以很遠的前景不算遮擋（避免物體輪廓周圍出現一圈暗暈）。
- **模糊**：7 tap，權重 `exp(−|Δz| / (0.02·z + 0.002))`，深度差大就不混，AO 不會滲到物體邊緣外面。水平、垂直各做一次。
- **半徑**：預設 0.16 m，以室內家具的尺度設計。大場景可以加大，小東西要縮小。

## 合成

- `k = mix(1, ao, uAO · (1 − smoothstep(0.6, 2.5, 亮度)) · (1 − 0.5·窗外))`：AO 只壓暗不太亮的地方。
- 窗外像素再乘上 `ext`。判斷條件是沒有深度（天空），或使用者給的 GLSL 條件成立。
- 每個顏色通道的上限是 60：單一個過亮的像素（反光的火點）不會把 bloom 撐爆。

## Bloom

- **降採樣**：中心權重 4，加上四個角，再除以 8；做 6 層，每層解析度減半。
  第一層可以設 `bloomThresh`，預設是 0，也就是全部都會微微發光，接近真實鏡頭的光暈。
- **升採樣**：3×3 tent 濾波（權重 1-2-1），用加法混合疊回上一層，所以最上層是全部 6 層的總和。
- 強度：`uBloom = look.bloom / 層數 × 6`。

## 調色（照 shader 裡的順序）

| 步驟 | 公式或做法 | 預設 |
|---|---|---|
| bloom | `c += bloom × uBloom` | 0.04 |
| 曝光、白平衡 | `c *= exposure × wb` | 1、(1, 1, 1) |
| 暗角 | 乘上 `smoothstep(1.05, 0.25, 距中心距離)`，在套曲線**之前**做，等於鏡頭的光量衰減 | 0.15 |
| 分區偏色 | 暗部（亮度小於 0.25）用 shadowTint，亮部（0.35–1.6）用 highTint，中間用 midTint | 全部是 1 |
| 飽和度、增豔 | `gm` = 這個像素有多「綠」（綠色減掉紅藍中較大者），飽和度乘 `1 + vib·gm`，紅色再加一點，讓綠色偏黃綠 | sat 1.05、vib 0.3 |
| 對比 | `pow(c / 0.18, contrast) × 0.18`：以中灰為支點，中間調的亮度不變 | 1.02 |
| 淡入淡出 | `c *= fade` | 1 |
| 膠片曲線 | Uchimura（GT 曲線）：toe（m 0.22、c 1.33），接著長的線性段，最後是柔和的肩部收到 1 | — |
| 曲線的套法 | 依亮度套用（色相不變）和逐通道套用（亮部會去飽和），兩者以 55% 混合 | — |
| 高光 | 最大通道超過 0.75 之後，往亮度的灰色混最多 60%：飽和的高光會往白色收，不會卡在純紅或純綠 | — |
| 輸出 | sRGB 轉換，加顆粒（暗部比較多），再加 1/255 的 dither | grain 0.012 |

### 色調預設

| 名稱 | 內容 | 適合 |
|---|---|---|
| `neutral` | 全部是 1，sat 1.05 | 一般場景 |
| `dawn` | 原專案的設定：wb (0.9, 0.985, 1.14)、暗部 (0.9, 0.98, 1.12)、中間調 (0.97, 1, 1.04)、sat 1.1 | 清晨、陰天、冷調 |
| `warm` | wb (1.08, 1, 0.88)、中間調偏暖、暗部微冷、暗角 0.2 | 傍晚、室內燈光 |
| `flat` | 不加暗角、不加顆粒，sat 1、對比 1，bloom 0.04 | 對照、需要真實顏色的截圖 |

## 自適應解析度（`AdaptiveRes`）

- 每秒算一次平均影格時間。超過 24 ms 時解析度乘 0.88（最低 0.5）；低於 12.5 ms 時乘 1.08（最高 1）。
- 兩次調整至少相隔 1.5 秒，避免來回跳動。
- 一開始的寬度上限是 1600 px。
- canvas 要用 CSS 撐滿（`width: 100%`），內部解析度改用 `renderer.setSize(w, h, false)`。
- **60 Hz 螢幕的陷阱**：只呼叫 `tick(dt)` 時，量到的是 rAF 間隔，最快也只有 16.7 ms，永遠不會低於 12.5 ms，所以只會降、不會升。
  原專案也是這樣寫的。要能升回去，就把實測的算繪時間傳給第二個參數：`tick(dt, renderMs)`。範例每 30 格用 `gl.finish` 量一次。
- 實測：`?res=adaptive&slow=0` 會強制降解析度，幾秒內降到 0.53 倍（675×422），canvas 仍然撐滿 1280×800，畫面正常。

## 遇過的問題

| 症狀 | 原因 | 修法 |
|---|---|---|
| 整個畫面又暗又灰，只看得到一角亮光 | 鏡頭放在房間外面，看到的是牆的背面 | 先確認鏡頭在房間裡 |
| 燈罩被光暈蓋掉 | 點光源離牆 20 cm，牆上被照出一個極亮的光斑，bloom 把它擴散開 | 燈離牆 50 cm 以上，或把 bloom 降到 0.04，或設 `bloomThresh` |
| 預設看起來偏藍 | 原專案的 LOOK 是清晨的冷色調 | 中性的預設已經改成 1；原本的設定放在 `LOOKS.dawn` |
| 窗戶一片死白 | 窗外亮度是室內的好幾倍 | 設 `ext`（0.2–0.4），並給正確的 `ext` 條件式 |
| AO 在物體周圍出現暗暈 | 遠處的前景被當成遮擋 | `range` 項已經處理；如果還有，縮小 `aoRadius` |
| 錄影時 AO 和顆粒會閃 | `frame` 每格都在變 | 錄影時固定 `post.frame`，或把 grain 設成 0 |
| 牆面漸層有色帶 | 8-bit 輸出 | 已經加了 1/255 的 dither，不要拿掉 |
| 開了 renderer.toneMapping，畫面變得更灰更暗 | 被色調映射了兩次 | `Post` 會自動關掉，不要再打開 |

## 搬到 Godot／Unreal

- **Godot 4**：Environment 已經內建 SSAO、Glow、Tonemap。要做到這裡的效果：
  - 把曲線和分區偏色寫成 `CompositorEffect` 或全螢幕的 `canvas_item` shader，直接改寫 `FINAL_FS`。
  - 窗外分開曝光：在 shader 裡讀 `DEPTH_TEXTURE`，重建出世界座標後套用同樣的條件。
- **Unreal**：Post Process Volume 的 Color Grading（Shadows／Midtones／Highlights）和這裡的分區偏色對應；膠片曲線可以用 Film 的 Toe／Shoulder 調出接近的結果。
  窗外分開曝光可以寫成 Post Process Material：用 SceneDepth 重建 WorldPosition 後套用條件。
