# 藤蔓生長與葉片擺放

## 藤蔓：「軟繩」模型（`growVine`）

每一步長 `ds`（範例 1.5 cm），方向依序受到以下影響：

1. **左右與前後的漂移**：沿生長方向的 value noise，振幅為 `wander`。
2. **重力**：向下的力從 `bend0` 漸變到 `bend1`，在前 `ramp` 公尺完成過渡。
   - 靠近盆子時 bend0 小，藤蔓幾乎是硬的，會先往外伸出去。
   - 之後 bend1 變大，開始垂下。
3. **尾端上翹**：最後 `hookLen` 公尺朝 `hookDir` 拉，`hookDir` 由光源方向、偏好方向、往上三者混合。強度是 `hook × h²`，所以越接近尖端翹得越多。
4. **停在表面時**（被 Env 往上推，代表正躺在層板或桌面上）：往原本的方向 `head` 推，藤蔓會沿表面滑到邊緣再掉下去。
5. **避障**：新的位置用 `Env.push` 推到外面。推完如果幾乎沒前進（< 0.6 ds），就往 head 方向多推一點，避免卡住。
6. **節點**：每隔 `internode(s, 剩餘長度)` 有一個節點，在節點處左右交替彎折（`kink`），葉子就長在節點上。

## 每條藤蔓的參數（`vines` 陣列）

| 參數 | 意義 | 垂吊 | 往光源伸的長弧 |
|---|---|---|---|
| `th` | 方位角（度）。0 = +x，90 = +z | 依位置 | 朝光源 |
| `el` | 起始仰角（度） | 30–50 | 30–40 |
| `len` | 長度（公尺） | 0.6–1.5 | 1.3–2 |
| `b0` / `b1` / `ramp` | 重力起點、終點、過渡長度 | 0.22 / 0.1 / 0.3 | 0.012 / 0.085 / 0.7 |
| `hook` / `hookLen` | 尾端上翹的強度與長度 | 0.38 / 0.14 | 0.42 / 0.18 |
| `wander` / `kink` | 漂移量、節點彎折量 | 0.012 / 0.2 | 同左 |

**往光源伸的長弧**：b0 很小，所以前 0.7 m 幾乎水平伸出去，之後才慢慢垂下，尾端再翹起來。這是窗邊黃金葛最有辨識度的樣子。

**shoots**（盆中央的新芽）：`n` 條短莖，往上長（仰角 52–86°）、幾乎不受重力，葉子全部算「冠部」，負責讓盆子上方看起來飽滿。

## 每盆的參數（`growPlant`）

| 參數 | 意義 |
|---|---|
| `cx`, `cz`, `rIn`, `rimY`, `soilY` | 盆中心、內半徑、盆緣高度、土面高度 |
| `light` | 光源位置。葉面朝它轉 0.35、往它傾 0.15，藤蔓尾端也朝它翹 |
| `bias` | 這盆整體偏好的方向（例如朝向房間），讓葉子朝外 |
| `size` | 葉片長度範圍（公尺）。大盆 7.8–11.8 cm，小盆 5.6–9 cm |
| `stemR` | 莖的半徑：根部、尖端 |
| `inter` | 節間長度範圍（垂吊段）。靠近盆子與尖端的節間比較短 |
| `bare` | 垂吊的老莖段上，節點不長葉的機率 |
| `seg` | 莖的管子每段長度（決定網格密度） |

## 葉片怎麼放（`addLeaf`）

1. **冠部程度**（crown）：盆緣附近、剛出盆的節點為 1，垂下的部分為 0。冠部的葉子比較大、比較挺、比較朝上；垂吊的葉子比較小、比較下垂。
2. **嫩葉程度**（young）：靠近尖端的最後 11 cm。嫩葉小 55%、偏黃綠，用第 6 種「還沒展開、對折」的葉形。
3. 葉柄從節點往側面伸出，方位角左右交替 35–105°，長度依大小和冠部程度決定。
4. 葉片方向：
   - Y（葉尖方向）= 葉柄方向 × 0.6 − 下垂量 + 朝外 0.2 + 朝光 0.15 + 隨機。
   - Z（葉面法線）= 朝外 0.5 + 往上 0.38–0.95 + 朝光 0.35 + 偏好方向 0.5 + 隨機。
   - 再隨機滾轉 ±0.32 rad。
5. **探針避障**：在葉片上取 8 個點，加上該葉形的高度，用 Env 檢查有沒有撞到東西。
   - 撞到的話，往推開的方向轉動 Y 和 Z，並把葉片移出一點。
   - 第 6 次之後還撞到，就開始把葉片縮小 12%。
   - 12 次都失敗就放棄這片葉子。
6. 葉柄做成二次貝茲曲線，從節點側向出發，最後接到葉片的中肋方向。
7. 顏色：每片葉子 ±12% 亮度。嫩葉偏黃；1.2% 機率是發黃的老葉。

## 氣根

垂吊段、非冠部的節點有 40% 機率長出一小段氣根（0.5–1.3 cm），朝下、朝牆，顏色是褐色。
