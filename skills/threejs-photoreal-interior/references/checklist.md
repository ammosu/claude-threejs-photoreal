# 驗收清單

## 每次改完都看
- [ ] 主控台沒有錯誤，也沒有警告（例如 three r187 已經移除 `PCFSoftShadowMap`，用 `PCFShadowMap`）。
- [ ] `window.__stats`：三角形數、建立時間，以及每個垂掛的 `p99Stretch`（小於 0.2）、`inside`（個位數）。
- [ ] 烘焙：`applied` 等於網格數，`stale` 是 0。

## 光照
- [ ] `?view=gi`：四個角落、牆腳、窗洞四邊都沒有亮線或亮點；靠窗的一側比較亮；天花板比地板暗。
- [ ] 把太陽關掉（在 console 設 `scene.traverse(o => o.isDirectionalLight && (o.visible = false))`），確認亮點不是即時陰影漏光。
- [ ] 每件放在桌上或地上的物件，底部都有接觸陰影。
- [ ] 有貼圖的材質都有 `albedo`，反彈光沒有偏白。

## 材質
- [ ] 掠射光的鏡頭（貼著牆看）：牆的凹凸要看得出來，但不能像月球表面。
- [ ] 高光的鏡頭：桌面的使用痕跡、杯子的釉面、金屬的反射都在正確的位置（box projection）。
- [ ] 貼圖重複時看不到接縫（`seamScore` 約等於 1）。

## 物件
- [ ] 從四個方向和上方看主角物件，都沒有穿模。
- [ ] 小物都貼著支撐面，沒有浮空也沒有下陷；布料的下擺不會穿進椅面或籃子。
- [ ] 每件小物都有理由在那裡（生活感），沒有排得整整齊齊。

## 畫面
- [ ] 窗外看得到東西（`ext` 0.2–0.4），室內曝光正常。
- [ ] 強光源附近的物體看得出形狀（bloom 不要太強）。
- [ ] 和 three.js ACES 對照，暗部和高光都比較好看。

## 數字的參考範圍（範本與原專案的實測）

| 項目 | 範圍 |
|---|---|
| 天空亮度 | zenith 約 0.3–0.5、horizon 約 0.85–1.15（線性） |
| 太陽照度 | 約 3–3.5 |
| 室內地板平均 E | 約 0.02（只有天光）到 0.1（陽光照進來時） |
| 曝光 | 約 4.5（有烘焙的室內） |
| `ext` | 0.2–0.4 |
| 細分 | 放東西的表面 1.5–2 cm，大型家具 4–6 cm，牆 8 cm |
| 毛巾垂掛 | D 1.5 cm、0.4 × 0.9 m、約 0.65 s |
| 烘焙 spp | 預覽 32、正式 128–256（1024 和 256 幾乎看不出差別） |
