# 窗外遠景

## 只建看得到的東西（`windowVisibility`）

- 窗洞是一條**有厚度的隧道**：一個點必須同時穿過窗洞的內側面和外側面，才算看得到。
- 做法：
  - 在房間裡沿深度方向取 16 個眼睛平面（`eyeZ`）。
  - 每個平面上，把窗洞內、外兩個面投影過去，取交集。
  - 再和人實際會站的範圍（`eyeX`，以及眼睛高度 `eyeY`）取交集，結果不為空就算看得到。
- `lod(x, y, z)` 的回傳值：
  - 0：從哪裡都看不到。
  - 1：只有斜看才看得到（側向斜率大於 1.35，或仰角斜率大於 1.2），可以變稀疏。
  - 2：正常看得到。
- 搭配 `threejs-procedural-vegetation` 的 `makeTree(..., { lodAt: vis.lod })`：
  - lod 0 的細枝只留一張大卡片，機率 0.55。房間看不到它，但烘焙時還是有樹蔭。
  - lod 1 的葉片間距乘 2.3、卡片放大 1.45 倍。
- 原專案另外有 `keep()`：從房間到鄰居紅屋頂之間，留一條視線走廊，讓樹葉不要擋住。可以傳給 `makeTree` 的 `keep`。
- 範例實測：從二樓的窗往外看時，大部分樹都看得到，所以省得不多（−17%）。省下的主要是貼著外牆、在窗戶兩側的樹。
  如果房子周圍有更多樹，或者窗戶比較小，效果會更明顯。

## 大氣霧化（`hazePatch`）

- 距離超過 `start`（10 m）之後，顏色以 `1 − exp(−(距離 − start) · density)` 混向霧的顏色。density 0.006 時，60 m 外約混到 26%，100 m 外約 42%。
- 霧的顏色：地平線附近的天空亮度乘 0.8。有烘焙的室內場景，還要再乘上天空的 `display`，原專案是 `giScale · giExt · 0.3`。
- 這個補丁會保留材質原本的 `onBeforeCompile`（例如 GI 補丁），可以疊加使用。
- 從外面俯瞰時（`?cam=out`），整片都會變得很淡，因為霧是依相機距離計算的。它是為「從窗戶往外看」設計的。

## 元件

| 函式 | 內容 | 數值 |
|---|---|---|
| `lawn` | 草地網格：範圍內 1.6 m 一格，範圍外每一格放大 1.6 倍，一直到 260 m；頂點色有斑駁的深淺與黃綠 | 網格要夠密，烘焙時樹蔭才落得上去 |
| `grassTexture` | 9000 筆草葉，可重複 | repeat 每 2.5 m 一次 |
| `gravelPath` | 沿 `pathZ(x)` 的 1.7 m 寬碎石路，中間被踩得比較亮 | |
| `hedge` | 圓角的剖面沿路掃出，高度 0.9–1.1 m 起伏 | 原專案在看得到的地方再貼葉片卡片（植物 skill 的 `Leaves.blob`） |
| `houses` | 山牆屋：牆、陶瓦屋頂（出簷 45 cm）、白色封簷板、雨水槽、屋脊瓦、磚煙囪加帽、正面三排窗、山牆一扇窗、兩扇天窗 | 用清單給位置與尺寸 |
| `roofTexture` | 交錯排列的陶瓦：每片有筒瓦明暗、上一排的陰影、下緣受光，還有苔蘚和髒污 | 一次重複是 8 × 8 片 = 2.4 × 2.72 m |
| `windowTexture` | 兩片玻璃（天空色漸層）、窗框陰影、紗簾 | 對應 1.16 × 1.5 m 的窗 |
| `crownWall` + `crownTexture` | 半徑 100 m 的圓柱帶（約 ±87°），往內貼上三層樹冠剪影；`alphaTest` 0.5 | 每 64 m 重複一次，高 20 m；放在真正的樹後面封住地平線 |
| `Soup` | 把四邊形細分到 `maxEdge` | 烘焙的光存在頂點上，大面一定要細分 |

## 遇過的問題

| 症狀 | 原因 | 修法 |
|---|---|---|
| 清晨天空的平均亮度只有解析式的 73% | 雲色改成跟著漸層縮放，清晨的漸層偏暗，雲就跟著變暗 | 雲色改回絕對亮度（原專案的寫法），並用 `measureDome` 調每個預設 |
| 從房間看出去，窗戶被一棵樹整個擋住 | 主樹離窗戶太近，正好在視線中央 | 把主樹移到兩側（x −4.5 和 9.5）；中景留空隙給房子和天空 |
| 可見性裁切前後葉片數一樣 | 從二樓的窗戶，所有的樹都在可見範圍內 | 這是正常的；裁切主要對窗戶兩側、貼近外牆的東西有效 |
| 從室內看，牆亮得跟戶外一樣 | 不烘焙時，半球光也會照進室內 | 室內材質調暗約 4 倍；正式做法是用 `threejs-baked-gi` 烘焙 |
| 測試伺服器起不來 | 在同一行指令裡用 `pkill -f "http.server …"`，把自己這個 shell 也殺掉了 | 分開執行，或用 `exec` 啟動伺服器 |
| 遠處有一塊白色跟著視角移動 | 鏡頭 far（100）比遠景短（樹牆 R 100、草地延伸 260 m），被切掉的那一圈露出天空球的地平線霧帶，切口跟著鏡頭轉 | far 大於最遠的東西（範本用 400 m；near 0.02 時深度精度仍夠） |

## 搬到其他引擎

- **Godot**：天空可以改寫成 `shader_type sky;`（`EYEDIR` 就是這裡的 d），同一個 Sky 也會成為環境光的來源；霧化改用 Environment 的 Fog 或自己寫的 depth fog。
- **Unreal**：天空可以寫成材質，貼在 SkySphere 上，或使用 Sky Atmosphere 加 Volumetric Clouds，但兩者的平均亮度要另外對齊。遠景房子和樹牆可以匯出 GLB 後放成 HLOD。
- `windowVisibility` 是純數學，可以照搬，用在任何引擎的建置階段裁切。
