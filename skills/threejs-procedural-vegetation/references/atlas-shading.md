# 葉片圖集與葉片 shader

## 圖集（`buildAtlas`）

4×4 格，每格的葉梗都從底部中央進入。共三張貼圖：
- 顏色：2048 px，sRGB。
- 法線：2048 px。
- 參數：1024 px，R 是葉片薄度（越薄越透光），G 是光澤，B 是每片小葉的隨機 id。

| 列 | 內容 | 函式 |
|---|---|---|
| 0 | 刺槐風格：成對的羽狀複葉、三支一叢、扇形 | `pairTile`、`sprayTile`、`fanTile` |
| 1 | 白蠟風格：羽狀複葉、單片複葉 | 同上加 `singleTile` |
| 2 | 椴樹風格：細枝上互生的單葉 | `simpleTile(sp, 片數)` |
| 3 | 葉叢：中景、遠景、樹籬用 | `clusterTile(片數, sp, 叢數)` |

每片小葉（`leaf()`）都會做這些處理：
- 依年齡變色：8% 嫩葉偏亮偏黃、薄、霧面；9% 老葉偏深、厚、常有蠟質光澤。
- 底下的葉片會被蓋上接觸陰影（`source-atop`）。
- 從葉柄到葉尖有漸層，V 形對折造成一半亮、一半暗，還有隨機的色斑和葉脈。
- 法線圖畫出葉片的傾斜、對折、杯狀或反捲、葉尖捲曲。

### 圖集處理的兩個關鍵

1. **透明像素填色**：完全透明的像素填入該格的平均葉色。否則 mip 取樣時，綠色葉緣會混進黑色或白色而出現描邊。
2. **保留覆蓋率的 mip**：每一層 mip 都先算「該格原本有多少比例 ≥ alpha 0.5」，再把 alpha 放大，讓 alpha test 之後的覆蓋率一樣。
   不處理的話，遠景樹會越來越稀疏（這是 alpha test 樹葉最常見的問題）。
   `atlas.cover`（範例約 0.19）是卡片的平均不透明比例；給烘焙用時，可以拿來設定光直接穿過的比例 `thru`。

## 葉片 shader（`leafMaterial`）

頂點階段：
- 圖集座標：`aLeaf.xy` 是格子左下角。一半的卡片左右鏡像（依隨機相位決定），讓同一格看起來不重複。
- 葉片翻動：繞葉梗扭轉（`lTw`）加上點頭（`lNod`），振幅隨陣風變化；法線也一起修正，所以翻動時亮度會閃。
- 整張卡片跟著它所在的枝條擺動（`windOffset(錨點)`）。

片段階段（依序疊加）：
1. 依開放度調色：內側偏深偏冷，外側偏黃偏亮。
2. **朝下的那面就是葉背**：偏淡、偏灰、霧面（× 0.74，降低飽和度）。
3. 樹冠內部調暗：`× mix(0.42, 1.05, aOpen)`。
4. 每格自己的遮蔭：複葉越靠近細枝越暗，葉叢中心較暗。
5. **透光**：太陽從葉子背面照過來時（`−dot(N, sun) > 0`），加上 `顏色 × (1.4, 1.15, 0.4) × (0.3 + 0.7·薄度²)`，嫩葉透出黃綠色。
6. **天空反光**：只有光澤高的小葉、朝向開闊天空時才出現。卡片側面對著鏡頭時不反光，避免出現一條亮線。

可以調整的參數：`leafMaterial(atlas, { sheen: 1.3, translucency: 0.6 })`。

## 樹皮

`barkMaps()` 產生 512 px 的貼圖：
- 蜿蜒的縱向溝紋（正弦加上 domain warp）。
- 橫向裂紋。
- 青苔斑塊（偏綠、偏暗）。

shader 讓上方亮、下方暗（× 0.7–1.22），在葉子之間的空隙裡，枝條才看得出立體結構。
