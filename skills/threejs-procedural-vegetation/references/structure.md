# 骨架與葉片擺放

## 生長的基本動作

- `grow(rng, p0, d0, len, n, up0, up1, wig)`：從 p0 沿方向 d0 長 n 段。每段方向會加一點隨機擺動（`wig·√段長`），並從 up0 漸變到 up1 的向上力道。
  - 正值往上翹，負值往下垂。主枝用 0.2→−0.07，是先往上再慢慢下垂的弧線。
- `at(b, t)`：沿枝條取第 t（0–1）位置的點和切線。
- `dirAround(tg, a, phi)`：從切線 tg 偏轉 a 弧度。phi = 0 是水平側邊，π/2 是往上。

## 樹（`makeTree`）參數

| 參數 | 意義 | 主樹範例 |
|---|---|---|
| `H`, `R` | 樹高、樹冠半徑（公尺） | 14, 4.3 |
| `trunk` | 樹幹長度佔樹高的比例 | 0.5 |
| `first` | 第一根主枝的高度（佔樹幹比例） | 0.36–0.4 |
| `limbs` | 主枝數 | 8–9 |
| `az0` | 第一根主枝的方位角；之後每根加 2.39996 rad（黃金角），所以不會重疊 | |
| `lean` | 樹幹傾斜 [x, z] | ±0.04 |
| `d2`, `d3` | 每公尺主枝上的枝數；每公尺枝上的細枝數 | 2.8–3, 6 |
| `sparse` | 葉片間距倍率，越大越稀疏 | 1 |
| `dens`, `size` | 中景、遠景：每公尺的葉叢數與葉叢大小 | 13, 0.72 |
| `extra` | 指定方向的主枝：`[{ t, to: [x, y, z] }]`，例如讓一根枝伸向窗戶 | |
| `y` | 地面高度 | 0 |

- 主枝傾角：下面的接近水平（1.2 rad），上面的接近直立（0.12 rad）。長度依「樹冠半徑 ÷ sin(傾角)」計算，並且不超過樹頂。
- 樹幹半徑：`r0 = H·0.019`，往上漸細，根部加粗（`1 + 1.1·e^(−18t)`）。
- 枝與細枝的粗細依長度決定，末端漸細到 4.5 mm、2.4 mm。

## 樹種（`SPECIES`）

| 欄位 | 意義 |
|---|---|
| `tiles` | 這個樹種從圖集挑哪幾格（可以重複，用來加權） |
| `card` | 一張葉片卡片的長度（公尺） |
| `droop` | 葉片下垂量的範圍 |
| `twig`, `twigUp` | 細枝長度；細枝上翹或下垂 |
| `droop2` | 枝的下垂 |
| `sp` | 細枝上葉片卡片的間距 |
| `light`, `deep` | 每張卡片色調的兩端（線性倍率）。卡片在兩端之間取色，2.5% 的卡片會偏黃，模擬發黃的葉子 |

新增樹種時：先在 `atlas.js` 畫新的葉形，排進某一列，再新增一個 SPECIES 項目指向它。

## 葉片卡片的朝向

- 錨點在細枝上，Y 軸沿著葉梗往外（左右交替，加上滾轉和下垂）。
- 卡片正面（Z 軸）朝「離開樹幹的方向 × 0.55 + 往上 0.7 + 隨機」。這樣外側的葉子大多朝外、朝上，從外面看樹冠是飽滿的。
- 卡片大小 = `card × 該格的縮放 × 0.8–1.2`。LOD 1 的卡片放大 1.45 倍，間距放大 2.3 倍。
- 細枝的 LOD 為 0（看不到的地方）時，有 55% 機率改放一張大的葉叢卡片，讓樹冠的剪影和遮蔭還在。

## 樹冠的「開放度」（aOpen）

原專案從烘焙讀取每片葉子的天空可見度。這裡用一個橢球近似：以樹冠中心為原點，正規化半徑越大、位置越高，開放度就越大。
shader 用它來：
- 把內側調暗（× 0.42–1.05）。
- 讓外側偏黃、偏亮，內側偏深、偏冷。
- 縮放透光和天空反光的強度。

如果場景有烘焙光照（threejs-baked-gi），可以改回讀取烘焙值。

## `keep` 回呼

`keep(x, y, z, rng) => boolean`，決定某處要不要長細枝或葉叢。用途舉例：
- 視線通道：原專案讓房間看得到對面屋頂，所以那條通道裡的葉子只留 5%。
- 不要長進牆裡或窗前。
